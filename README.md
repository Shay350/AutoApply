# AutoApply

A blank, shareable starter kit for AI-assisted job applications.

## What this repo includes
- `job-profile.md` — candidate profile template (fill in your own info)
- `INSTRUCTIONS.md` — workflow and autofill rules template
- `cover-letter-playbook.md` — reusable cover letter strategy template
- `resume-template.md` — placeholder source for experience bullets (optional)

## Quick start
1. Fill `job-profile.md` with your own details.
2. Add your own resume PDF to repo root (example: `My_Resume.pdf`).
3. Update `INSTRUCTIONS.md` defaults to match your preferences.
4. Keep secrets out of git (`.secrets/` is ignored).

## Safety for sharing
- This repo is intentionally scrubbed of personal data.
- Replace all placeholders before using for real applications.
- Never commit credentials, tokens, or private docs.
